# Calm Workspace Consistency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every personal-workspace page use a full-height, borderless, left-aligned Mineral Garden canvas; repair avatar rendering; and standardize date/time controls.

**Architecture:** Keep the existing rail / library / canvas information architecture. Move repeated visual rules into shared layout and field primitives, then let Inbox and Reports consume those primitives instead of drawing their own framed surfaces. The server resolves every private image attachment into a six-hour S3 access URL while serializing the enclosing business response; clients render that URL directly and never request attachment bytes for display.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, Vitest, Fastify, Drizzle, existing `@vital/api-client`.

**Spec:** `docs/vital-calm-productivity-design-system.md`

## Global Constraints

- Preserve Mineral Garden tokens: `#F3F3ED`, `#FAFAF6`, `#EAECE4`, and `#697C65`.
- Do not add permanent borders to reading, writing, or task surfaces; use background, type, spacing, and hover state for hierarchy.
- Keep current URLs and the rail / library / canvas navigation model unchanged.
- Date, time, and datetime controls use the same 36px height, 6px radius, focus ring, clear action, and elevated popover token.
